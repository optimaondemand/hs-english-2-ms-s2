# hs-english-2-ms-s2

Optima Academy Online - **English 2 (10th Grade), Semester 2 - Mississippi section**.

GitHub Pages host for the lesson pages embedded by the Mississippi Semester 2 kit
(`1001340-s2-ms` in the Course Kit). Semester 1 for this section lives in `hs-english-2-ms`.

Content is the Kings and Community Semester 2 build (Module 3 *A Midsummer Night's Dream*,
Module 4 *The Great Gatsby*) mapped against Florida B.E.S.T. 1001340, Texas TEKS 110.37,
and the Diocese of Jackson English II standards (codes in each page's `<head>` meta).

Items built solely for a diocesan standard carry `MS` in the lesson number and filename
(`M3_W6_L6.MS1_The_Same_Scene_Twice`, `M4_W2_L2.MS1_Three_Accounts_One_Subject`).
In this Mississippi section those items are **published**; in the Florida section
(`optimaondemand/hs-english-2-s2`, kit `1001340-s2`) they ship unpublished.

Repo is intentionally **flat** - no subdirectories. Lesson files are byte-identical to
`hs-english-2-s2`.
